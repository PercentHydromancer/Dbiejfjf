# Malik GPT — локальный ИИ без API-ключей

Самостоятельный проект с тёмным минималистичным интерфейсом в стиле современных чат-приложений. Это не ChatGPT и не копия его закрытых моделей, аккаунтов и инструментов.

## Настоящие функции

- Регистрация и вход, хранение истории чатов на сервере, поиск, переименование и удаление.
- Общение с **настоящими локальными моделями через Ollama**. Не нужны Groq, OpenAI и другие платные API-ключи.
- При ошибке одной установленной модели сервер автоматически пробует следующую **без искусственного 30-секундного таймера**. Время генерации и таймауты внешних процессов всё равно остаются.
- Режим «Код и файлы», скачивание текстового кода из ответов модели, ZIP из нескольких файлов.
- Независимый генератор стартового сайта: рабочие `index.html`, `style.css`, `script.js` и ZIP даже без локальной модели.
- Редактор текстовых файлов с сохранением на устройство.
- Загрузка текстовых файлов в поле сообщения (до 120 КБ); заметки пользователя.
- Мобильная адаптация и тёмная тема, близкая по характеру к интерфейсу ChatGPT.

Кнопки не имитируют платные или недоступные функции: нет неподключённой генерации изображений, VPN, голосового режима, оплаты и доступа к интернету.

## Быстрый запуск на ПК

1. Установи [Node.js 20+](https://nodejs.org/) и [Ollama](https://ollama.com/download).
2. Скачай две лёгкие модели в терминале:

```bash
ollama pull qwen2.5:3b
ollama pull llama3.2:3b
```

3. Если Ollama не запущена сама, запусти `ollama serve`.
4. В папке сайта:

```bash
npm install
npm start
```

5. Открой http://localhost:3000, зарегистрируйся и начни общение.

**Чтобы ИИ работал, Ollama и модели должны быть доступны с сервера сайта.** Просто разместить HTML на GitHub Pages недостаточно.

При необходимости настрой переменные среды:

```env
PORT=3000
DATA_DIR=./data
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODELS=qwen2.5:3b,llama3.2:3b
```

`OLLAMA_MODELS` — необязательный список приоритетных моделей. Другие установленные модели сервер также сможет использовать в качестве резерва.

## Docker Compose (ПК/VPS)

Есть `docker-compose.yml`: приложение и Ollama запускаются вместе, без публичного доступа к порту Ollama.

```bash
docker compose up -d --build
docker compose exec ollama ollama pull qwen2.5:3b
docker compose exec ollama ollama pull llama3.2:3b
```

Затем открой http://localhost:3000. На обычном CPU модели могут отвечать медленно. Для многопользовательского сервиса необходимы достаточные RAM, CPU/GPU и проверка производительности.

## Публикация на Render

**Render Free не содержит Ollama**, а обычный бесплатный Node-хостинг не предоставляет достаточно мощностей для большой модели. Нужно запустить Ollama на собственном ПК/VPS (сервер и модель должны быть постоянно доступны) или выбрать платную инфраструктуру с необходимой оперативной памятью. Адрес Ollama задаётся через `OLLAMA_BASE_URL`. **Не публикуй Ollama без защиты на открытом порту**: используй приватную сеть/VPN, аутентифицированный прокси.

Для хранения аккаунтов/чатов используется файл `DATA_DIR/store.json`. На Render Free файловая система временная, после деплоя записи могут исчезнуть. Для постоянного сервиса нужен постоянный диск или внешний БД-движок. Не продавай тарифы, пока не обеспечишь защиту, резервные копии и постоянное хранение.

## Проверка

- `/api/health` — статус приложения.
- Кнопка статуса в правом верхнем углу показывает доступные модели.
- Если Ollama не включена, интерфейс сообщает об этом вместо выдуманного ответа.
- Если модель не смогла ответить, вопрос сохранён и можно повторить попытку.

Проект — основа для самостоятельного развёртывания, а не прошедшая аудит система для большого числа пользователей. Для публичного запуска рекомендуется добавить внешнюю БД, журналирование, усиленные меры защиты и тесты под нагрузкой.
